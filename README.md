> ⚠️ **个人实盘项目 · 仅供学习参考**
>
> 这是我自己用来跑真钱的交易系统，不是产品，也没经过任何审计。
>
> - **不构成投资建议**，不保证盈利。历史表现不代表未来。
> - 默认 **50x 杠杆的永续合约**。**止损距离和爆仓线重合**（都是 1.5%），

## 它在做什么

15 分钟布林带的均值回归。价格贴轨 → 预期回归中轨 → 开仓。
出场交给交易所挂的 SL/TP 条件单，引擎这边只做动态推平和对账。

不是量化基金那套（不是因子、不是多策略、不是高频做市）。就是**一个策略跑久了，
用数据看它到底行不行，然后让模型自己从历史里学**。

## 设计上最要紧的一条

**模型管决策，代码管护栏。**

大模型只输出两个字段：`contract`（哪个品种）+ `side`（做多还是做空）。
价格、张数、止损、止盈、杠杆 —— **全部由代码按固定规则算**，不交给模型。

```
模型说"开 BTC 多"  →  代码决定在什么价、几张、SL 放哪、TP 放哪
```

这么分的原因很简单：模型会不稳定。同样的行情问它两次，可能给两个答案；
但代码算出来的 SL 永远是 1.5%。**把不确定的部分交给模型，把必须确定的部分锁死在代码里。**

## 跑起来

```bash
git clone https://github.com/yzx75/crypto-pilot.git
cd crypto-pilot
pip install -r requirements.txt
cp .env.example .env        # 然后填你的密钥
python launch.py --dry-run # 干跑，不下真单
```

确认没问题后去掉 `--dry-run`。Windows 也可以直接双击 `START.bat`。

`launch.py` 会依次检查 Python 版本 / `.env` / 依赖 → 拉起引擎 → 健康检查 → 打印看板地址。
其他参数：`--port 9000` 换端口，`--stop` 停引擎。

看板在 `http://127.0.0.1:8801`（可用 `--port` 改）。

## 密钥怎么填

复制 `.env.example` 为 `.env`，至少要填两个：

| 变量 | 干什么用 |
|---|---|
| `GATE_KEY` / `GATE_SECRET` | Gate.io API 密钥对 |
| `CLOUD_BASE_URL` / `CLOUD_API_KEY` / `CLOUD_MODEL` | 决策模型通道（任何 OpenAI 兼容接口都行） |

Gate 密钥在 Gate.io → 个人中心 → API 管理 里创建。
**建议交易和看板用两个不同的 key**，各自给最小必要权限。

## 四个线程

| 线程 | 周期 | 干什么 |
|---|---|---|
| `watcher` | 2s | 拉全池行情落盘 |
| `hf` | 60s | 扫全池 → 拼 brief → 调模型 → 开仓 |
| `guard` | 2s | 对账、动态绳追盈、孤儿仓兜底 |
| `review` | 300s | 教训聚合（现在主要靠平仓事件驱动，周期是空的） |

### 出场怎么管

- **SL / TP 是挂在交易所的条件单**，不是引擎里下的 —— 引擎崩了你也不会裸奔
- **动态绳**：浮盈到一定程度就自动推 SL 追峰值，回吐超过 20% 就落袋
- **分批止盈**：武装后先平 40%，余仓 SL 推保本，继续追
- **孤儿仓兜底**：有仓但引擎没记录时，自动补挂保护性 SL

## 自我迭代那一圈

这是这个项目后来做的重点，说人话就是：**让系统用自己的成交数据，检验自己到底行不行。**

每笔开仓都会打四个标签：

| 标签 | 取值 |
|---|---|
| `mom_dir` | 顺动能 / 逆动能（1 小时涨跌方向） |
| `pos_zone` | 贴下轨 / 中轨区 / 上轨区 / 追高 |
| `regime` | range / squeeze / wide |
| `entry_src` | deep / seq / wm / touch（形态来源） |

平仓后按 `trade_id` 把开仓和平仓配对，算出每个标签组合的真实胜率和盈亏，
**注入到模型每轮看到的 brief 里**。模型下一次开仓时，就知道自己上次这类情况赢没赢。

另外平仓后会调一次反思模型，生成一句「什么情况下该做什么」的教训。
教训**只记亏损单**并且**按标签聚合**（带真实战绩），正常盈利单走"最近交易回顾"那段。

```
[聚合] 顺动能×追高×其他×touch | 出现 5 次 | 胜率 80%（4/5）| 累计 +0.244U
```

**样本量不足 20 时会明说"样本太少"** —— 不拿 2 笔 100% 之类的巧合当结论。

### 为什么不给模型写死规则

一开始我给提示词写了六条"铁律"（比如"wide 档不许开"、"顺 1H 动能胜率 69%"）。
结果模型被这些数字绑死，明明该开的时候也不开 —— **连续 2.5 小时零开仓**。

后来全删了，只留指标读法 + **系统自己跑出来的真实数据**。
教训部分也只保留有战绩支撑的，没验证过的单条规则不给模型看。

**判断权 100% 在模型，代码只提供信息和护栏。**

## 代码结构

```
engine.py          四线程编排 + 平仓对账 + 孤儿仓兜底
server.py          唯一入口：拉起引擎 + FastAPI 看板
config.yaml        所有参数（品种池/仓位数/阈值/模型）
watchdog.py        三层判活，引擎卡死自动拉起

core/              config / state（原子写）/ log / indicators（纯函数）
market/feeder.py   K线与现价，带缓存
exchange/          Gate API 签名 + 下单执行层
strategy/boll.py   布林状态机（形态标注的来源）
strategy/regime.py 行情定性（**市场状态**标签，非仓位池）：breakout_up/dn ·
                  trend_up/dn · range / squeeze / wide
risk/manager.py    全部数字在这里算，模型碰不到
agents/decision.py 扫池 → 拼 brief → 调模型 → 开仓
agents/review.py   教训生成与标签聚合
web/               看板
cloud/             云端只读镜像（手机上看，不执行交易）
```

## 几个踩过的坑

写在前面，因为这些不是"你照着做就没事"的项目。

**止损和爆仓线重合。** 50x 杠杆下 1.5% 止损 ≈ 1.5% 爆仓。跳空就穿仓。
真要长期跑，**建议先把杠杆降下来**。

**手续费是主要成本。** 早先 240 笔的统计：毛利 −1.73U，手续费 −3.48U。
高频交易在手续费面前很容易变成"忙一天全交学费"。

**单边行情下这套参数不适用。** 极端行情（比如 8.19）单边波幅能到 6~12%，
而止损只有 1.5% —— 连续几根 K 线就出局。没有 regime 熔断。

**持仓 24 小时以上资金套死。** 数据里见过扛了 26 小时的单。
我没加"持仓超时强平"，因为那属于决策护栏，违背这套设计的原则。

## 依赖

只有四个，都很轻：

```
fastapi / uvicorn   看板
pyyaml              读config.yaml
psutil              watchdog 判活（缺了它会静默判「引擎不存在」→ 无限重启，务必装）
```

行情和下单走 Python 标准库的 `urllib`，**不需要 requests**。
指标计算是纯 Python 实现，**不需要 numpy/pandas**。
